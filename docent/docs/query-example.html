Query<T>

Executes a SQL query and returns a list of mapped entities with strict type safety.

ℹ Strict Mapping Mode

By default, Query<T> uses strict mapping. All properties on T must have matching columns in the result set, or an InvalidOperationException is thrown.

Declaration

public static List<T> Query<T>(
    this IDbConnection connection,
    string sql,
    object? parameters = null,
    CommandOptions<T>? options = null,
    CancellationToken cancellationToken = default)
where T : new()

Parameters

Name Type Description
connection IDbConnection The database connection to execute the query against.
sql string The SQL query to execute. Supports both named and positional parameters.
parameters object? Optional parameters for the query.
options CommandOptions<T>? Optional command options for transaction, timeout, or custom mapper.
cancellationToken CancellationToken Optional token to cancel the query operation.

Returns

List<T> - A list of entities mapped from the query results.

Examples

Basic Query

var products = connection.Query<Product>("SELECT * FROM products");

Query with Parameters

var products = connection.Query<Product>(
    "SELECT * FROM products WHERE category_id = @CategoryId",
    new { CategoryId = 5 });

Exceptions

Type Condition
InvalidOperationException Property has no matching column (strict mode).
ArgumentException Parameter count mismatch.
DbException Database operation failed.
