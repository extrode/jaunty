Installation

Get Jaunty up and running in your .NET project.

Requirements

  • .NET Standard 2.0 or .NET 8.0+
  • Any ADO.NET provider (SQLite, SQL Server, PostgreSQL, MySQL, etc.)

Install via NuGet

dotnet add package Beparey.Jaunty

Install via Package Manager

Install-Package Beparey.Jaunty

Target Frameworks

Jaunty is built for multi-targeting:

  • netstandard2.0 - Broad compatibility with .NET Framework 4.6.1+, .NET Core 2.0+, and .NET 5+
  • net8.0 - Optimized for modern .NET with FrozenDictionary and other performance improvements

Automatic Framework Selection

The NuGet package automatically selects the appropriate build for your project's target framework. No configuration needed!

Database Providers

Jaunty works with any ADO.NET provider. Popular options include:

SQLite

dotnet add package System.Data.SQLite.Core

SQL Server

dotnet add package Microsoft.Data.SqlClient

PostgreSQL

dotnet add package Npgsql

MySQL

dotnet add package MySqlConnector

Verify Installation

Create a simple test to verify Jaunty is working:

using Jaunty;
using System.Data.SQLite;

using var connection = new SQLiteConnection("Data Source=:memory:");
connection.Open();

// Test query
var result = connection.QueryScalar<long>("SELECT 1");
Console.WriteLine($"Jaunty is working! Result: {result}");
