# Code of Conduct

- Be respectful and inclusive in all interactions.
- Focus on constructive feedback.
- Welcome contributors of all skill levels.

Harassment, personal attacks and discrimination are not acceptable. The maintainer may remove
comments, close issues and pull requests, or block accounts that break these rules.

Report a conduct problem privately through a
[GitHub Security Advisory](https://github.com/extrode/jaunty/security/advisories/new) or by contacting
the maintainer through their GitHub profile. Contributions also require a signed
[CLA](CLA.md); see [CONTRIBUTING.md](CONTRIBUTING.md).
