Query Methods

Query<T>

Executes SQL and maps results to a list of T with strict mapping (all properties must have matching columns).

Signatures

public static List<T> Query<T>(string sql) where T : new()
public static List<T> Query<T>(string sql, object parameters) where T : new()
public static List<T> Query<T>(string sql, CommandOptions<T> options) where T : new()
public static List<T> Query<T>(string sql, object parameters, CommandOptions<T> options) where T : new()

Parameters

  • sql (string): The SQL query to execute
  • parameters (object, optional): Anonymous object containing parameter values
  • options (CommandOptions<T>, optional): Command execution options

Returns

List<T>: A list of objects of type T

Exceptions

  • InvalidOperationException: Thrown when strict mapping fails (property without matching column)

Example

var products = connection.Query<Product>(
    "SELECT id AS Id, name AS Name, price AS Price FROM products WHERE category_id = @CategoryId",
    new { CategoryId = 1 });

QueryPartial<T>

Executes SQL and maps only matching columns to T (partial mapping).

Signatures

List<T> QueryPartial<T>(string sql) where T : new()
List<T> QueryPartial<T>(string sql, object parameters) where T : new()
List<T> QueryPartial<T>(string sql, CommandOptions<T> options) where T : new()
List<T> QueryPartial<T>(string sql, object parameters, CommandOptions<T> options) where T : new()

Parameters

  • sql (string): The SQL query to execute
  • parameters (object, optional): Anonymous object containing parameter values
  • options (CommandOptions<T>, optional): Command execution options

Returns

List<T>: A list of objects of type T with only matching properties set

Example

var summaries = connection.QueryPartial<ProductSummary>(
    "SELECT id AS Id, name AS Name FROM products");

Scalar Methods

QueryScalar<T>

Returns the first column of the first row as type T.

Signatures

T QueryScalar<T>(string sql)
T QueryScalar<T>(string sql, object parameters)
T QueryScalar<T>(string sql, CommandOptions<T> options)
T QueryScalar<T>(string sql, object parameters, CommandOptions<T> options)

Parameters

  • sql (string): The SQL query to execute
  • parameters (object, optional): Anonymous object containing parameter values
  • options (CommandOptions<T>, optional): Command execution options

Returns

T: The value of the first column of the first row

Example

var count = connection.QueryScalar<long>("SELECT COUNT(*) FROM products");
var maxPrice = connection.QueryScalar<decimal>("SELECT MAX(price) FROM products WHERE category_id = @CategoryId", new { CategoryId = 1 });

Multiple Result Methods

QueryMultiple

Executes SQL that returns multiple result sets and returns a GridReader.

Signatures

GridReader QueryMultiple(string sql)
GridReader QueryMultiple(string sql, object parameters)
GridReader QueryMultiple(string sql, CommandOptions options)
GridReader QueryMultiple(string sql, object parameters, CommandOptions options)

Returns

GridReader: A reader for accessing multiple result sets

Example

using var gridReader = connection.QueryMultiple(
    "SELECT * FROM categories; SELECT * FROM products; SELECT COUNT(*) FROM orders");

var categories = gridReader.Read<Category>().ToList();
var products = gridReader.Read<Product>().ToList();
var orderCount = gridReader.ReadScalar<long>();

Streaming Methods

QueryStream<T>

Executes SQL and returns an enumerable that yields results one at a time (memory efficient for large result sets).

Signatures

IEnumerable<T> QueryStream<T>(string sql) where T : new()
IEnumerable<T> QueryStream<T>(string sql, object parameters) where T : new()
IEnumerable<T> QueryStream<T>(string sql, CommandOptions<T> options) where T : new()
IEnumerable<T> QueryStream<T>(string sql, object parameters, CommandOptions<T> options) where T : new()

Returns

IEnumerable<T>: An enumerable that yields results lazily

Example

var products = connection.QueryStream<Product>(
    "SELECT * FROM products WHERE category_id = @CategoryId",
    new { CategoryId = 1 });

foreach (var product in products)
{
    // Process each product without loading all into memory
    ProcessProduct(product);
}

Async Methods

Example

var products = await connection.QueryAsync<Product>(
    "SELECT * FROM products WHERE category_id = @CategoryId",
    new { CategoryId = 1 },
    cancellationToken);

Command Options

CommandOptions provides a unified way to pass transaction and timeout settings without method overloading confusion.

Static Methods

CommandOptions<T> CommandOptions<T>.WithMapper(Func<IDataReader, T> mapper)
CommandOptions<T> CommandOptions<T>.WithTransaction(IDbTransaction transaction)
CommandOptions<T> CommandOptions<T>.WithTimeout(int seconds)
CommandOptions<T> CommandOptions<T>.With(Func<IDataReader, T> mapper, IDbTransaction transaction, int timeoutSeconds)

CommandOptions CommandOptions.WithTransaction(IDbTransaction transaction)
CommandOptions CommandOptions.WithTimeout(int seconds)
CommandOptions CommandOptions.With(IDbTransaction transaction, int timeoutSeconds)

Example

// Timeout only
var products = connection.Query<Product>(
    "SELECT * FROM products",
    CommandOptions.WithTimeout(30));

// Transaction only
using var transaction = connection.BeginTransaction();
var products = connection.Query<Product>(
    "SELECT * FROM products",
    CommandOptions.WithTransaction(transaction));

// Both
var products = connection.Query<Product>(
    "SELECT * FROM products",
    CommandOptions.With(transaction, timeoutSeconds: 30));

Attributes

Attributes for customizing mapping behavior.

[Table]

Specifies the database table that a class is mapped to.

Constructor

TableAttribute(string name, string? schema = null)

Properties

  • Name (string): The table name
  • Schema (string?): The schema name (optional)

Example

[Table("order_items")]
public class OrderItem
{
    public int Id { get; set; }
    public string Name { get; set; }
}

[Column]

Specifies the database column that a property is mapped to.

Constructor

ColumnAttribute(string name)

Properties

  • Name (string): The column name

Example

public class OrderItem
{
    [Column("item_id")]
    public int Id { get; set; }

    [Column("product_name")]
    public string Name { get; set; }
}

[Ignore]

Indicates that a property should be ignored during mapping.

Example

public class Product
{
    public int Id { get; set; }
    public string Name { get; set; }
    
    [Ignore]
    public decimal CalculatedValue { get; set; } // Not mapped from database
}

Configuration

Global configuration for naming conventions.

JauntyConfig

public static class JauntyConfig
{
    public static Func<Type, string>? SchemaNameResolver { get; set; }
    public static Func<Type, string>? TableNameResolver { get; set; }
    public static Func<string, string>? ColumnNameResolver { get; set; }
    
    public static void Reset();
}

NamingConvention Helper Class

public static class NamingConvention
{
    public static string ToSnakeCase(string propertyName);
    public static string ToLowerCase(string propertyName);
    public static string Pluralize(string singular);
    public static string SnakeCasePluralTable(Type type);
    public static string SnakeCaseColumn(string propertyName);
}

Example

// At application startup
JauntyConfig.ColumnNameResolver = NamingConvention.ToSnakeCase;  // ProductName -> product_name
JauntyConfig.TableNameResolver = NamingConvention.SnakeCasePluralTable;  // Product -> products

// Reset configuration
JauntyConfig.Reset();
