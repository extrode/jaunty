Advanced Parameter Binding

Jaunty now supports advanced parameter binding features that make working with complex queries easier:

Collection Parameter Expansion

Jaunty can now expand collections for use in IN clauses:

// Before: Manual parameter expansion
var ids = new[] { 1, 2, 3, 4, 5 };
var placeholders = string.Join(", ", ids.Select((_, i) => $"@id{i}"));
var sql = $"SELECT * FROM products WHERE category_id IN ({placeholders})";
var products = connection.Query<Product>(sql, new { id0 = 1, id1 = 2, id2 = 3, id3 = 4, id4 = 5 });

// With Jaunty's CollectionParameterHelper:
var (updatedSql, parameters) = CollectionParameterHelper.ExpandInClause<int>(
    "SELECT * FROM products WHERE category_id IN @ids",
    new[] { 1, 2, 3, 4, 5 },
    "ids");

var products = connection.Query<Product>(updatedSql, parameters);

Complex Type Parameters

Support for nested objects as parameters:

public class ProductFilter
{
    public int? CategoryId { get; set; }
    public decimal? MinPrice { get; set; }
    public decimal? MaxPrice { get; set; }
    public bool? Discontinued { get; set; }
}

var filter = new ProductFilter { CategoryId = 1, MinPrice = 10.00m, MaxPrice = 100.00m };
var products = connection.Query<Product>(
    @"SELECT * FROM products 
      WHERE (@CategoryId IS NULL OR category_id = @CategoryId)
        AND (@MinPrice IS NULL OR unit_price >= @MinPrice)
        AND (@MaxPrice IS NULL OR unit_price <= @MaxPrice)
        AND (@Discontinued IS NULL OR discontinued = @Discontinued)",
    filter);

Bulk Operations

Jaunty now provides high-performance bulk operations for inserting, updating, and deleting multiple records:

Bulk Insert

// Insert multiple products efficiently
var products = new[]
{
    new Product { Name = "Product 1", Price = 10.00m, CategoryId = 1 },
    new Product { Name = "Product 2", Price = 20.00m, CategoryId = 1 },
    new Product { Name = "Product 3", Price = 30.00m, CategoryId = 2 }
};

var affectedRows = connection.BulkInsert(products, "products");

// Async version
var affectedRows = await connection.BulkInsertAsync(products, "products");

Bulk Update

// Update multiple products efficiently
var products = new[]
{
    new Product { Id = 1, Name = "Updated Product 1", Price = 15.00m },
    new Product { Id = 2, Name = "Updated Product 2", Price = 25.00m }
};

var affectedRows = connection.BulkUpdate(products, "products", "Id");

// Async version
var affectedRows = await connection.BulkUpdateAsync(products, "products", "Id");

Bulk Delete

// Delete multiple records by IDs
var ids = new object[] { 1, 2, 3, 4, 5 };
var affectedRows = connection.BulkDelete<Product>(ids, "products", "Id");

// Async version
var affectedRows = await connection.BulkDeleteAsync<Product>(ids, "products", "Id");

// Delete with WHERE condition
var affectedRows = connection.DeleteWhere<Product>(
    "products", 
    "category_id = @CategoryId AND discontinued = @Discontinued", 
    new { CategoryId = 1, Discontinued = true });

// Async version
var affectedRows = await connection.DeleteWhereAsync<Product>(
    "products", 
    "category_id = @CategoryId AND discontinued = @Discontinued", 
    new { CategoryId = 1, Discontinued = true });

Single Entity Operations

// Insert single entity
var product = new Product { Name = "New Product", Price = 10.00m, CategoryId = 1 };
var affectedRows = connection.Insert(product, "products");

// Async insert
var affectedRows = await connection.InsertAsync(product, "products");

// Update single entity
product.Price = 15.00m;
var affectedRows = connection.Update(product, "products", "Id");

// Async update
var affectedRows = await connection.UpdateAsync(product, "products", "Id");

// Delete single entity by ID
var affectedRows = connection.Delete<Product>(1, "products", "Id");

// Async delete
var affectedRows = await connection.DeleteAsync<Product>(1, "products", "Id");

Batch Operations

Execute multiple commands in a single batch operation for improved performance:

Basic Batch Execution

// Execute multiple commands in a single batch
var commands = new[]
{
    new BatchCommand("INSERT INTO categories (category_name) VALUES (@Name)", new { Name = "New Category" }),
    new BatchCommand("INSERT INTO products (product_name, category_id) VALUES (@Name, @CategoryId)", new { Name = "New Product", CategoryId = 1 }),
    new BatchCommand("UPDATE products SET unit_price = unit_price * 1.1 WHERE category_id = @CategoryId", new { CategoryId = 1 })
};

var totalAffected = connection.ExecuteBatch(commands);

// Async version
var totalAffected = await connection.ExecuteBatchAsync(commands);

Batch Operations with Transaction

// Execute batch operations within a transaction
var commands = new[]
{
    new BatchCommand("INSERT INTO orders (customer_id, order_date) VALUES (@CustomerId, @OrderDate)", new { CustomerId = 1, OrderDate = DateTime.Now }),
    new BatchCommand("INSERT INTO order_details (order_id, product_id, quantity) VALUES (@OrderId, @ProductId, @Quantity)", new { OrderId = 1, ProductId = 1, Quantity = 2 })
};

var totalAffected = connection.ExecuteBatchInTransaction(commands);

// Async version
var totalAffected = await connection.ExecuteBatchInTransactionAsync(commands);

Dynamic Parameters

Jaunty now supports dynamic parameters for more flexible query construction:

Dynamic Parameters Usage

// Create dynamic parameters
var dynamicParams = new DynamicParameters();
dynamicParams.Add("CategoryId", 1);
dynamicParams.Add("MinPrice", 10.00m);
dynamicParams.Add("MaxPrice", 100.00m);

var products = connection.Query<Product>(
    "SELECT * FROM products WHERE category_id = @CategoryId AND unit_price BETWEEN @MinPrice AND @MaxPrice",
    dynamicParams);

// Create from anonymous object
var dynamicParams2 = new DynamicParameters(new { CategoryId = 1, MinPrice = 10.00m });

// Add more parameters dynamically
dynamicParams2.Add("MaxPrice", 100.00m);

Table-Valued Parameter Support

For SQL Server, Jaunty now provides support for Table-Valued Parameters:

TVP Usage

// Create a TVP parameter for SQL Server
var products = new[]
{
    new Product { Id = 1, Name = "Product 1", Price = 10.00m },
    new Product { Id = 2, Name = "Product 2", Price = 20.00m }
};

var tvpParam = TableValuedParameterHelper.CreateTvpParameter(
    "@ProductList", 
    products, 
    "ProductTableType");

// Use in query
var result = connection.QueryScalar<int>(
    "EXEC ProcessProductList @ProductList", 
    new { ProductList = tvpParam });

Feature Summary

With these new features, Jaunty now provides:

  • Complete CRUD Operations: Full Create, Read, Update, Delete functionality
  • High-Performance Bulk Operations: Efficient handling of large datasets
  • Advanced Parameter Binding: Support for collections, complex types, and dynamic parameters
  • Batch Operations: Execute multiple commands efficiently
  • SQL Server TVP Support: Table-Valued Parameter functionality
  • Consistent API Design: Same patterns for sync and async operations
  • Transaction Support: Proper transaction handling across all operations
  • Command Options: Unified way to specify timeouts and transactions

These additions bring Jaunty closer to feature parity with other ORMs like Dapper while maintaining its core philosophy of respecting your SQL and providing predictable, high-performance data access.
