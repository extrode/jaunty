The Micro-ORM That Respects Your SQL

Jaunty is a high-performance data access library for .NET that executes your SQL and maps results to objects with strict, predictable behavior.

Get Started API Reference

Strict by Default

Every property must have a matching column. Catch mapping errors early instead of dealing with silent partial mapping bugs.

High Performance

Compiled expression trees, metadata caching, and minimal allocations ensure maximum performance.

Clean API

Simple, intuitive methods that read like intent rather than ceremony.

Getting Started

Installation

dotnet add package Beparey.Jaunty

Basic Usage

using Jaunty;

var products = connection.Query<Product>(
    "SELECT id AS Id, name AS Name, price AS Price FROM products WHERE category_id = @CategoryId",
    new { CategoryId = 1 });

Partial Mapping

// Only map columns that exist
var summaries = connection.QueryPartial<ProductSummary>(
    "SELECT id AS Id, name AS Name FROM products");

API Reference

Query Methods

Query<T>

Executes SQL and maps results to a list of T with strict mapping (all properties must have matching columns).

public static List<T> Query<T>(string sql) where T : new()
public static List<T> Query<T>(string sql, object parameters) where T : new()
public static List<T> Query<T>(string sql, CommandOptions<T> options) where T : new()
public static List<T> Query<T>(string sql, object parameters, CommandOptions<T> options) where T : new()

QueryPartial<T>

Executes SQL and maps only matching columns to T (partial mapping).

public static List<T> QueryPartial<T>(string sql) where T : new()
public static List<T> QueryPartial<T>(string sql, object parameters) where T : new()

QueryScalar<T>

Returns the first column of the first row as type T.

public static T QueryScalar<T>(string sql)
public static T QueryScalar<T>(string sql, object parameters)

Async Methods

All query methods have async counterparts:

  • QueryAsync<T>
  • QueryPartialAsync<T>
  • QueryScalarAsync<T>
  • QueryFirstAsync<T>
  • QuerySingleAsync<T>
  • QueryMultipleAsync

Streaming Methods

For large result sets:

  • QueryStream<T>
  • QueryStreamAsync<T>
  • QueryPartialStream<T>
  • QueryPartialStreamAsync<T>

Examples

Parameter Binding

Named Parameters

var products = connection.Query<Product>(
    "SELECT * FROM products WHERE category_id = @CategoryId AND price > @MinPrice",
    new { CategoryId = 1, MinPrice = 10.00m });

Positional Parameters

var products = connection.Query<Product>(
    "SELECT * FROM products WHERE category_id = @CategoryId",
    1); // @CategoryId = 1

Multiple Positional Parameters

var products = connection.Query<Product>(
    "SELECT * FROM products WHERE price BETWEEN @MinPrice AND @MaxPrice AND category_id = @CategoryId",
    10.00m, 100.00m, 2); // @MinPrice=10.00, @MaxPrice=100.00, @CategoryId=2

Transactions and Timeouts

using var transaction = connection.BeginTransaction();

var orders = connection.Query<Order>(
    "SELECT * FROM orders WHERE customer_id = @CustomerId",
    new { CustomerId = 123 },
    CommandOptions.With(transaction, timeoutSeconds: 30));

transaction.Commit();

Async with Cancellation

var products = await connection.QueryAsync<Product>(
    "SELECT * FROM products WHERE category_id = @CategoryId",
    new { CategoryId = 1 },
    CommandOptions.WithTimeout(15),
    cancellationToken);

Multiple Result Sets

using var gridReader = connection.QueryMultiple(
    "SELECT * FROM categories; SELECT * FROM products; SELECT COUNT(*) FROM orders");

var categories = gridReader.Read<Category>().ToList();
var products = gridReader.Read<Product>().ToList();
var orderCount = gridReader.ReadScalar<long>();

Configuration

Global Configuration

Configure naming conventions at application startup:

// At application startup
JauntyConfig.ColumnNameResolver = NamingConvention.ToSnakeCase;  // ProductName -> product_name
JauntyConfig.TableNameResolver = NamingConvention.SnakeCasePluralTable;  // Product -> products

// Custom naming
JauntyConfig.TableNameResolver = type => $"tbl_{type.Name.ToLower()}";
JauntyConfig.ColumnNameResolver = prop => $"col_{prop.ToLower()}";

Attribute Mapping

using Jaunty.Attributes;

[Table("order_items")]
public class OrderItem
{
    [Column("item_id")]
    public int Id { get; set; }

    [Column("product_name")]
    public string Name { get; set; }

    [Ignore]  // Not mapped from database
    public decimal CalculatedDiscount { get; set; }
}

Command Options

// Timeout only
var products = connection.Query<Product>(
    "SELECT * FROM products",
    CommandOptions.WithTimeout(30));

// Transaction only
using var transaction = connection.BeginTransaction();
var products = connection.Query<Product>(
    "SELECT * FROM products",
    CommandOptions.WithTransaction(transaction));

// Both
var products = connection.Query<Product>(
    "SELECT * FROM products",
    CommandOptions.With(transaction, timeoutSeconds: 30));
