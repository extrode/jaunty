Stored Procedure Output Parameters

Working with input, output, and return parameters in stored procedures

Home > Overview > Stored Procedure Output Parameters

Overview

Jaunty provides comprehensive support for stored procedures with input, output, and return parameters through the SpParameters class. This allows you to call stored procedures that return values through output parameters or return values.

SpParameters Class

The SpParameters class provides methods for defining stored procedure parameters with different directions.

SpParameters.AddInput(string name, object? value)

Adds an input parameter to the stored procedure call.

public SpParameters AddInput(string name, object? value)

Parameters

Name Type Description
name string The parameter name (without @ prefix)
value object? The parameter value

Returns

SpParameters: The same instance for fluent chaining

Example

var parameters = new SpParameters()
    .AddInput("CategoryId", 1)
    .AddInput("MinPrice", 10.00m);

SpParameters.AddInput(string name, object? value, DbType dbType, int? size = null)

Adds an input parameter with explicit database type and optional size.

public SpParameters AddInput(string name, object? value, DbType dbType, int? size = null)

Parameters

Name Type Description
name string The parameter name (without @ prefix)
value object? The parameter value
dbType DbType The database type

Returns

SpParameters: The same instance for fluent chaining

Example

var parameters = new SpParameters()

Retrieving Parameter Values After Execution

SpParameters.Get<T>(string name)

Gets the value of an output or input/output parameter after the stored procedure has been executed.

public T? Get<T>(string name)

Type Parameters

  • T: The expected type of the parameter value

Parameters

Name Type Description
name string The parameter name

Returns

T?: The parameter value converted to the specified type, or null if the parameter doesn't exist or has a null value

Example

var parameters = new SpParameters()
    .AddInput("CategoryId", 1)
    .AddOutput("TotalProducts", DbType.Int32);

// Execute the stored procedure
var results = connection.ExecuteStoredProcedure<Product>("GetProductsByCategory", parameters);

// Get the output parameter value after execution
var totalProducts = parameters.Get<int>("TotalProducts");
Console.WriteLine($"Total products in category: {totalProducts}");

SpParameters.GetReturnValue()

Gets the return value after the stored procedure has been executed.

public int GetReturnValue()

Returns

int: The return value as an integer

Example

var parameters = new SpParameters()
    .AddInput("CategoryId", 1)
    .AddReturnValue();

// Execute the stored procedure
var results = connection.ExecuteStoredProcedure<Product>("GetProductsByCategory", parameters);

// Get the return value after execution
var returnValue = parameters.GetReturnValue();
Console.WriteLine($"Stored procedure returned: {returnValue}");

SpParameters.HasValue(string name)

Checks if a parameter exists and has a non-null value after execution.

public bool HasValue(string name)

Parameters

Name Type Description
name string The parameter name

Returns

bool: True if the parameter exists and has a non-null, non-DBNull value

Example

var parameters = new SpParameters()
    .AddInput("CategoryId", 1)
    .AddOutput("LastModified", DbType.DateTime);

// Execute the stored procedure
var results = connection.ExecuteStoredProcedure<Product>("GetProductsByCategory", parameters);

// Check if the output parameter has a value
if (parameters.HasValue("LastModified"))
{
    var lastModified = parameters.Get<DateTime>("LastModified");
    Console.WriteLine($"Last modified: {lastModified}");
}

Stored Procedure Methods with Output Parameters

ExecuteStoredProcedure<T>(string procedureName, SpParameters parameters, CommandOptions<T> options = default)

Executes a stored procedure with input, output, and return parameters and returns the results as a list of entities. Output parameter values can be retrieved from the SpParameters object after execution.

public static List<T> ExecuteStoredProcedure<T>(this IDbConnection connection, string procedureName, SpParameters parameters, CommandOptions<T> options = default) where T : new()

Parameters

Name Type Description
connection IDbConnection The database connection
procedureName string The name of the stored procedure to execute
parameters SpParameters The parameters including input, output, and return parameters
options CommandOptions<T> Command options (transaction, timeout, custom mapper)

Returns

List<T>: A list of entities of type T returned by the stored procedure

Example

var parameters = new SpParameters()
    .AddInput("CategoryId", 1)
    .AddOutput("TotalProducts", DbType.Int32)
    .AddReturnValue();

var products = connection.ExecuteStoredProcedure<Product>(
    "GetProductsByCategory", 
    parameters);

// Retrieve output parameter value after execution
var totalProducts = parameters.Get<int>("TotalProducts");
var returnValue = parameters.GetReturnValue();

Console.WriteLine($"Retrieved {products.Count} products, total count: {totalProducts}, return value: {returnValue}");

ExecuteStoredProcedureAsync<T>(string procedureName, SpParameters parameters, CommandOptions<T> options = default, CancellationToken cancellationToken = default)

Asynchronously executes a stored procedure with input, output, and return parameters and returns the results as a list of entities. Output parameter values can be retrieved from the SpParameters object after execution.

public static Task<List<T>> ExecuteStoredProcedureAsync<T>(this IDbConnection connection, string procedureName, SpParameters parameters, CommandOptions<T> options = default, CancellationToken cancellationToken = default) where T : new()

Parameters

Name Type Description
connection IDbConnection The database connection
procedureName string The name of the stored procedure to execute
parameters SpParameters The parameters including input, output, and return parameters
options CommandOptions<T> Command options (transaction, timeout, custom mapper)
cancellationToken CancellationToken Cancellation token

Returns

Task<List<T>>: A task that resolves to a list of entities of type T returned by the stored procedure

Example

var parameters = new SpParameters()
    .AddInput("CategoryId", 1)
    .AddOutput("TotalProducts", DbType.Int32)
    .AddReturnValue();

var products = await connection.ExecuteStoredProcedureAsync<Product>(
    "GetProductsByCategory", 
    parameters);

// Retrieve output parameter value after execution
var totalProducts = parameters.Get<int>("TotalProducts");
var returnValue = parameters.GetReturnValue();

Console.WriteLine($"Retrieved {products.Count} products, total count: {totalProducts}, return value: {returnValue}");

Complete Example

Here's a complete example showing how to use stored procedure output parameters:

// Define the parameters
var spParams = new SpParameters()
    .AddInput("CategoryId", 1)
    .AddInput("MinPrice", 10.00m)
    .AddOutput("ProductCount", DbType.Int32)
    .AddOutput("AveragePrice", DbType.Decimal)
    .AddInputOutput("LastProcessed", DateTime.UtcNow, DbType.DateTime)
    .AddReturnValue();

// Execute the stored procedure
var products = connection.ExecuteStoredProcedure<Product>(
    "GetProductsByCategoryAndMinPrice", 
    spParams);

// Retrieve output parameter values after execution
var productCount = spParams.Get<int>("ProductCount");
var avgPrice = spParams.Get<decimal>("AveragePrice");
var lastProcessed = spParams.Get<DateTime>("LastProcessed");
var returnValue = spParams.GetReturnValue();

Console.WriteLine($"Retrieved {products.Count} products");
Console.WriteLine($"Total count: {productCount}");
Console.WriteLine($"Average price: {avgPrice}");
Console.WriteLine($"Last processed: {lastProcessed}");
Console.WriteLine($"Return value: {returnValue}");

Best Practices

Always Check Parameter Values After Execution

Always retrieve output parameter values after the stored procedure has completed execution:

var parameters = new SpParameters()
    .AddInput("CategoryId", 1)
    .AddOutput("TotalProducts", DbType.Int32);

var products = connection.ExecuteStoredProcedure<Product>("GetProductsByCategory", parameters);

// Get the output parameter value AFTER execution
var totalProducts = parameters.Get<int>("TotalProducts");  // Correct

Use Explicit DbType for Output Parameters

Always specify the DbType for output parameters to ensure proper type handling:

// Good - specify DbType for output parameters
var parameters = new SpParameters()
    .AddOutput("Count", DbType.Int32)  // Explicit type
    .AddOutput("Total", DbType.Decimal)  // Explicit type
    .AddOutput("LastModified", DbType.DateTime);  // Explicit type

// Avoid - without explicit DbType, the behavior may be inconsistent
var badParameters = new SpParameters()
    .AddOutput("Count", null);  // Type not specified

Important Notes

  • Parameter Names: Parameter names should not include the @ prefix when using SpParameters
  • Execution Order: Output parameter values can only be retrieved after the stored procedure has been executed
  • DbType Specification: For output parameters, it's important to specify the DbType to ensure proper type handling
  • Return Values: Return values are typically integers representing success/failure codes
  • Input/Output Parameters: These parameters serve as both input and output, allowing bidirectional data flow
  • Async Support: All stored procedure methods with output parameters have both synchronous and asynchronous variants
  • Transaction Support: Output parameters work with transactions when using CommandOptions
