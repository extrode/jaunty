Attributes

Mapping attributes for customizing entity and property mapping behavior

Home > Overview > Attributes

Overview

Jaunty provides several attributes for customizing how entities and their properties are mapped to database tables and columns. These attributes take precedence over global configuration and provide fine-grained control over mapping behavior.

Available Attributes

[Table(string name, string? schema = null)]

Maps an entity class to a specific database table and schema.

[AttributeUsage(AttributeTargets.Class, AllowMultiple = false, Inherited = false)]

Parameters

  • name: The name of the database table
  • schema: Optional schema name (defaults to null)

Properties

  • Name: Gets the table name
  • Schema: Gets the optional schema name

Usage Example

[Table("products", Schema = "inventory")]
public class Product
{
    public int ProductId { get; set; }
    public string ProductName { get; set; } = string.Empty;
}

[Column(string name)]

Maps a property to a specific database column name.

[AttributeUsage(AttributeTargets.Property, AllowMultiple = false, Inherited = false)]

Parameters

  • name: The name of the database column

Properties

  • Name: Gets the column name

Usage Example

public class Product
{
    [Column("product_id")]
    public int ProductId { get; set; }
    
    [Column("product_name")]
    public string ProductName { get; set; } = string.Empty;
    
    [Column("unit_price")]
    public decimal Price { get; set; }
}

[Ignore]

Excludes a property from database mapping operations.

[AttributeUsage(AttributeTargets.Property, AllowMultiple = false, Inherited = false)]

Usage Example

public class Product
{
    public int ProductId { get; set; }
    public string ProductName { get; set; } = string.Empty;
    
    [Ignore]  // This property will not be mapped from the database
    public string? ComputedDisplayName { get; set; }
    
    [Ignore]  // This property will not be included in INSERT/UPDATE operations
    public decimal CalculatedTax => Price * 0.08m;
}

[Key]

Indicates that a property is a primary key. Used for UPDATE and DELETE operations to identify the record to modify.

[AttributeUsage(AttributeTargets.Property, AllowMultiple = false, Inherited = false)]

Usage Example

public class Product
{
    [Key]  // Used for UPDATE/DELETE operations to identify the record
    public int ProductId { get; set; }
    
    public string ProductName { get; set; } = string.Empty;
    public decimal Price { get; set; }
}

// For composite primary keys
public class ProductCategory
{
    [Key]
    public int ProductId { get; set; }
    
    [Key]
    public int CategoryId { get; set; }
    
    public DateTime AssignedAt { get; set; }
}

[DatabaseGenerated(DatabaseGeneratedOption option)]

Specifies how a property's value is generated by the database.

[AttributeUsage(AttributeTargets.Property, AllowMultiple = false, Inherited = false)]

Parameters

  • option: The database generation option

DatabaseGeneratedOption Values

  • None: The database does not generate values
  • Identity: The database provides an identity value (auto-increment)
  • Computed: The database computes the value (e.g., timestamp, computed column)

Usage Example

public class Product
{
    [Key]
    [DatabaseGenerated(DatabaseGeneratedOption.Identity)]
    public int ProductId { get; set; }  // Will be populated with generated value after INSERT
    
    public string ProductName { get; set; } = string.Empty;
    public decimal Price { get; set; }
    
    [DatabaseGenerated(DatabaseGeneratedOption.Computed)]
    public DateTime DateModified { get; set; }  // Computed by database
}

Attribute Priority

Jaunty uses the following priority order for determining table/column names:

  1. Attributes ([Table], [Column], [Ignore], [Key], [DatabaseGenerated]) - Highest priority
  2. JauntyConfig resolvers (SchemaNameResolver, TableNameResolver, ColumnNameResolver) - Medium priority
  3. Default behavior (property/type names) - Lowest priority

Example of Priority Order

// If you have this global configuration:
JauntyConfig.ColumnNameResolver = NamingConvention.ToSnakeCase;

// And this entity:
[Table("legacy_products")]  // This overrides global TableNameResolver
public class Product
{
    [Column("legacy_product_id")]  // This overrides global ColumnNameResolver
    public int ProductId { get; set; }  // Would normally map to "product_id" with snake_case
    
    public string ProductName { get; set; }  // This will use snake_case: "product_name"
}

Best Practices

Use Attributes for Exceptions

Use attributes when you need specific column or table names that differ from your global configuration:

// Global configuration for snake_case
JauntyConfig.ColumnNameResolver = NamingConvention.ToSnakeCase;

// Specific override for this property
public class Product
{
    [Column("legacy_product_id")]  // Override the global convention
    public int ProductId { get; set; }
    
    public string ProductName { get; set; }  // This will use snake_case: "product_name"
}

Mark Primary Keys

Always mark primary key properties for UPDATE and DELETE operations:

public class Order
{
    [Key]  // Required for Update/Delete operations
    public int OrderId { get; set; }
    
    public DateTime OrderDate { get; set; }
    public decimal TotalAmount { get; set; }
    
    [Ignore]  // Computed property, not in database
    public decimal Tax => TotalAmount * 0.08m;
}

Mark Identity Columns

Mark identity/auto-increment columns with [DatabaseGenerated(DatabaseGeneratedOption.Identity)]:

public class Product
{
    [Key]
    [DatabaseGenerated(DatabaseGeneratedOption.Identity)]
    public int ProductId { get; set; }  // Value will be returned by Insert operations
    
    public string ProductName { get; set; } = string.Empty;
    public decimal Price { get; set; }
}

Integration with Configuration

Attributes work seamlessly with global configuration options:

// Global configuration
JauntyConfig.ColumnNameResolver = NamingConvention.ToSnakeCase;
JauntyConfig.TableNameResolver = type => $"{type.Name}s";  // Pluralize table names

// Entity with specific overrides
[Table("legacy_products")]  // Override global table name resolver
public class Product
{
    [Key]
    [Column("legacy_prod_id")]  // Override global column name resolver
    public int ProductId { get; set; }
    
    // Other properties will use global configuration
    // ProductName -> product_name (via ColumnNameResolver)
    public string ProductName { get; set; } = string.Empty;
    public decimal Price { get; set; }
}
