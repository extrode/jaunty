Multiple Result Sets

Execute SQL commands that return multiple result sets and read from each sequentially

Home > Overview > Multiple Result Sets

Overview

Multiple result set methods allow executing a single command that returns multiple result sets (typically from stored procedures or batch queries with multiple SELECT statements). The GridReader class provides access to each result set sequentially.

Key Concepts

  • Each command can return multiple result sets
  • Results are accessed sequentially through the GridReader
  • Once a result set is consumed, you cannot go back to it
  • Each result set can be read with different mapping modes (strict or partial)

QueryMultiple Methods

QueryMultiple(string sql)

Executes a command that returns multiple result sets and returns a GridReader for reading from each result set.

public static GridReader QueryMultiple(this IDbConnection connection, string sql)

Parameters

Name Type Description
connection IDbConnection The database connection
sql string The SQL command containing multiple result sets (e.g., multiple SELECT statements separated by semicolons)

Returns

GridReader: A reader for accessing multiple result sets sequentially

Example

using var gridReader = connection.QueryMultiple("SELECT * FROM categories; SELECT * FROM products");
var categories = gridReader.Read<Category>().ToList();
var products = gridReader.Read<Product>().ToList();

GridReader Methods

The GridReader provides methods to read from each result set in sequence.

Read<T>(CommandOptions<T> options = default)

Reads the current result set as a list of entities using strict mapping mode.

public List<T> Read<T>(CommandOptions<T> options = default) where T : new()

Parameters

Name Type Description
options CommandOptions<T> Command options (custom mapper, transaction, timeout)

Returns

List<T>: A list of entities of type T from the current result set

Example

using var gridReader = connection.QueryMultiple("SELECT * FROM categories; SELECT * FROM products");
var categories = gridReader.Read<Category>().ToList();  // Reads first result set
var products = gridReader.Read<Product>().ToList();    // Reads second result set

ReadPartial<T>(CommandOptions<T> options = default)

Reads the current result set as a list of entities using partial mapping mode. Only maps properties with matching columns in the result set.

public List<T> ReadPartial<T>(CommandOptions<T> options = default) where T : new()

Parameters

Name Type Description
options CommandOptions<T> Command options (custom mapper, transaction, timeout)

Returns

List<T>: A list of entities of type T from the current result set with partial mapping

Example

using var gridReader = connection.QueryMultiple("SELECT category_id, category_name FROM categories; SELECT product_id, product_name FROM products");
var categories = gridReader.ReadPartial<Category>().ToList();  // Only maps CategoryId and CategoryName
var products = gridReader.ReadPartial<Product>().ToList();    // Only maps ProductId and ProductName

ReadFirst<T>(CommandOptions<T> options = default)

Reads the first entity from the current result set using strict mapping mode. Throws an exception if the result set is empty.

public T ReadFirst<T>(CommandOptions<T> options = default) where T : new()

Parameters

Name Type Description
options CommandOptions<T> Command options (custom mapper, transaction, timeout)

Returns

T: The first entity of type T from the current result set

Example

}

Important Notes

  • Sequential Access: Result sets must be read in sequence; once a result set is consumed, you cannot go back to it
  • Resource Management: The GridReader implements IDisposable and should be properly disposed after use
  • Connection State: The underlying connection remains open while the GridReader is active
  • Database Support: Multiple result sets are supported by SQL Server, PostgreSQL, and MySQL but have limitations in SQLite
  • Mapping Modes: Each read method supports both strict and partial mapping modes
  • Async Requirements: Async operations require a DbConnection rather than just IDbConnection

Best Practices

Use Using Statement

Always dispose the GridReader properly:

using var gridReader = connection.QueryMultiple("SELECT * FROM categories; SELECT * FROM products");
var categories = gridReader.Read<Category>().ToList();
var products = gridReader.Read<Product>().ToList();

Handle Empty Result Sets

Use ReadFirstOrDefault or ReadSingleOrDefault when the result set might be empty:

using var gridReader = connection.QueryMultiple("SELECT * FROM categories WHERE category_id = 999; SELECT * FROM products");
var category = gridReader.ReadFirstOrDefault<Category>();  // Returns null if no results
var products = gridReader.Read<Product>().ToList();         // Returns empty list if no results
