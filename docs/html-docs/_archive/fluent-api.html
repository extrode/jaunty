Fluent API

Type-safe query builder with LINQ-like syntax for constructing SQL queries

Home > Overview > Fluent API

Overview

The Jaunty Fluent API provides a type-safe, LINQ-like query builder that enables constructing SQL queries using method chaining. This API offers compile-time validation and IntelliSense support for building complex queries.

Key Features

Type Safety

All operations are strongly typed, preventing runtime errors caused by typos in column names.

Method Chaining

Fluent interface allows chaining operations for readable and expressive query construction.

Compile-Time Validation

Property names are validated at compile time, preventing runtime errors.

Getting Started

From<T>(IDbConnection connection, string? alias = null)

Entry point for the fluent query API. Creates a query builder for the specified entity type.

public static IFromClause<T> From<T>(this IDbConnection connection, string? alias = null) where T : new()

Parameters

Name Type Description
connection IDbConnection The database connection
alias string? Optional alias for the table (useful for joins with string-based conditions)

Returns

IFromClause<T>: A fluent query builder for chaining operations

Example

// Basic query
var products = connection.From<Product>()
    .Select();

// With alias for joins
var products = connection.From<Product>("p")
    .InnerJoin<Category>("c")
    .OnColumns("p.category_id", "c.id")
    .Select();

Where(Expression<Func<T, bool>> predicate)

Adds a WHERE condition using a strongly-typed expression predicate.

IWhereClause<T> Where(Expression<Func<T, bool>> predicate)

Parameters

Name Type Description
predicate Expression<Func<T, bool>> Expression representing the WHERE condition

Returns

IWhereClause<T>: Interface for chaining additional WHERE conditions

Example

var products = connection.From<Product>()
    .Where(p => p.CategoryId == 1)
    .Where(p => p.Price > 10.00m)
    .Select();

Returns

Pagination

Take(int count)

Limits the number of results returned (equivalent to LIMIT/TOP).

IFromClause<T> Take(int count)

Parameters

Name Type Description
count int The maximum number of results to return

Returns

IFromClause<T>: Interface for continuing the query after limiting results

Example

var products = connection.From<Product>()
    .OrderBy(p => p.ProductId)
    .Take(10)
    .Select();

Skip(int count)

Skips the specified number of results (equivalent to OFFSET).

IFromClause<T> Skip(int count)

Parameters

Name Type Description
count int The number of results to skip

Returns

IFromClause<T>: Interface for continuing the query after skipping results

Example

// Get products 11-20 (pagination)
var products = connection.From<Product>()
    .OrderBy(p => p.ProductId)
    .Skip(10)
    .Take(10)
    .Select();

Terminal Operations

Select()

Executes the query and returns all results as a list of entities using strict mapping mode.

List<T> Select()

Returns

List<T>: A list of entities of type T

Example

var products = connection.From<Product>()
    .Where(p => p.CategoryId == 1)
    .OrderBy(p => p.ProductName)
    .Select();

SelectAsync(CancellationToken cancellationToken = default)

Asynchronously executes the query and returns all results as a list of entities using strict mapping mode.

Task<List<T>> SelectAsync(CancellationToken cancellationToken = default)

Parameters

Name Type Description
cancellationToken CancellationToken Cancellation token

Returns

Task<List<T>>: A task that resolves to a list of entities of type T

Example

var products = await connection.From<Product>()
    .Where(p => p.CategoryId == 1)
    .OrderBy(p => p.ProductName)
    .SelectAsync();

SelectPartial(params Expression<Func<T, object?>>[] columns)

Selects only the specified columns using partial mapping mode.

List<T> SelectPartial(params Expression<Func<T, object?>>[] columns)

Parameters

Name Type Description
columns Expression<Func<T, object?>>[] Expressions selecting the properties to include in the result

Returns

List<T>: A list of entities of type T with only specified properties mapped

Example

var products = connection.From<Product>()
    .SelectPartial(p => p.ProductId, p => p.ProductName, p => p.Price);

Advanced Operations

WhereIn<TValue>(Expression<Func<T, TValue>> selector, IEnumerable<TValue> values)

Filters results where the selected property value is in the specified collection.

IWhereClause<T> WhereIn<TValue>(Expression<Func<T, TValue>> selector, IEnumerable<TValue> values)

Parameters

Name Type Description
selector Expression<Func<T, TValue>> Expression selecting the property to filter on
values IEnumerable<TValue> Collection of values to match against

Returns

IWhereClause<T>: Interface for chaining additional conditions

Example

var products = connection.From<Product>()
    .WhereIn(p => p.CategoryId, new[] { 1, 2, 3 })
    .Select();
