Streaming Methods

Memory-efficient methods for processing large result sets without loading all data into memory

Home > Overview > Streaming Methods

Overview

Streaming methods provide memory-efficient processing of large result sets by returning IEnumerable<T> or IAsyncEnumerable<T> instead of loading all results into memory at once. These methods are ideal for processing large datasets without consuming excessive memory.

Synchronous Streaming Methods

QueryStream<T>(string sql)

Executes a query and returns an enumerable sequence of entities using strict mapping mode. Results are processed lazily as they are enumerated.

public static IEnumerable<T> QueryStream<T>(this IDbConnection connection, string sql) where T : new()

Parameters

Name Type Description
connection IDbConnection The database connection
sql string The SQL query to execute

Returns

IEnumerable<T>: A lazy enumerable of entities of type T

Example

foreach (var product in connection.QueryStream<Product>("SELECT * FROM products"))
{
    // Process each product individually
    ProcessProduct(product);
}

Important Notes

  • The connection remains open during enumeration and should not be used for other operations until enumeration is complete
  • The underlying data reader is automatically disposed when enumeration completes
  • Uses strict mapping mode - all entity properties must have matching columns in the result set

QueryStream<T>(string sql, object parameters)

Executes a parameterized query and returns an enumerable sequence of entities using strict mapping mode. Results are processed lazily as they are enumerated.

public static IEnumerable<T> QueryStream<T>(this IDbConnection connection, string sql, object parameters) where T : new()

Parameters

Name Type Description
connection IDbConnection The database connection
sql string The SQL query to execute
parameters object Parameters for the query

Returns

IEnumerable<T>: A lazy enumerable of entities of type T

Example

foreach (var product in connection.QueryStream<Product>(
    "SELECT * FROM products WHERE category_id = @CategoryId", 
    new { CategoryId = 1 }))
{
    // Process each product individually
    ProcessProduct(product);
}

QueryStream<T>(string sql, CommandOptions<T> options)

Executes a query with command options and returns an enumerable sequence of entities using strict mapping mode. Results are processed lazily as they are enumerated.

public static IEnumerable<T> QueryStream<T>(this IDbConnection connection, string sql, CommandOptions<T> options) where T : new()

Parameters

Name Type Description
connection IDbConnection The database connection
sql string The SQL query to execute
options CommandOptions<T> Command options (transaction, timeout, custom mapper)

Returns

IEnumerable<T>: A lazy enumerable of entities of type T

Example

using var transaction = connection.BeginTransaction();
var products = connection.QueryStream<Product>(
    "SELECT * FROM products", 
    CommandOptions<Product>.WithTransaction(transaction));

foreach (var product in products)
{
    // Process each product
    ProcessProduct(product);
}

transaction.Commit();

Asynchronous Streaming Methods

QueryStreamAsync<T>(string sql, [EnumeratorCancellation] CancellationToken cancellationToken = default)

Asynchronously executes a query and returns an async enumerable sequence of entities using strict mapping mode. Results are processed lazily as they are enumerated.

public static IAsyncEnumerable<T> QueryStreamAsync<T>(this IDbConnection connection, string sql, [EnumeratorCancellation] CancellationToken cancellationToken = default) where T : new()

Parameters

Name Type Description
connection IDbConnection The database connection
sql string The SQL query to execute
cancellationToken CancellationToken Cancellation token for the operation

Returns

IAsyncEnumerable<T>: An async enumerable of entities of type T

Example

await foreach (var product in connection.QueryStreamAsync<Product>("SELECT * FROM products"))
{
    // Process each product individually
    await ProcessProductAsync(product);
}

Important Notes

  • Requires a DbConnection rather than just IDbConnection
  • The connection remains open during enumeration and should not be used for other operations until enumeration is complete
  • The underlying data reader is automatically disposed when enumeration completes
  • Uses strict mapping mode - all entity properties must have matching columns in the result set
  • Supports cancellation via the CancellationToken

Partial Mapping Streaming Methods

These methods use partial mapping mode, allowing entities to be mapped even if some properties don't have matching columns in the result set.

QueryPartialStream<T>(string sql)

Executes a query and returns an enumerable sequence of entities using partial mapping mode. Only properties with matching columns in the result set are mapped.

public static IEnumerable<T> QueryPartialStream<T>(this IDbConnection connection, string sql) where T : new()

Parameters

Name Type Description
connection IDbConnection The database connection
sql string The SQL query to execute

Returns

IEnumerable<T>: A lazy enumerable of entities of type T with partial mapping

Example

foreach (var product in connection.QueryPartialStream<Product>("SELECT product_id, product_name FROM products"))
{
    // Only ProductId and ProductName will be mapped, other properties will have default values
    ProcessProduct(product);
}

QueryPartialStreamAsync<T>(string sql, [EnumeratorCancellation] CancellationToken cancellationToken = default)

Asynchronously executes a query and returns an async enumerable sequence of entities using partial mapping mode. Only properties with matching columns in the result set are mapped.

public static IAsyncEnumerable<T> QueryPartialStreamAsync<T>(this IDbConnection connection, string sql, [EnumeratorCancellation] CancellationToken cancellationToken = default) where T : new()

Parameters

Name Type Description
connection IDbConnection The database connection
sql string The SQL query to execute
cancellationToken CancellationToken Cancellation token for the operation

Returns

IAsyncEnumerable<T>: An async enumerable of entities of type T with partial mapping

Example

await foreach (var product in connection.QueryPartialStreamAsync<Product>("SELECT product_id, product_name FROM products"))
{
    // Only ProductId and ProductName will be mapped, other properties will have default values
    await ProcessProductAsync(product);
}

Alternative Streaming Methods

Jaunty also provides alternative names for streaming methods:

  • QueryUnbuffered<T>() - Synchronous unbuffered query (alias to QueryStream)
  • QueryUnbufferedAsync<T>() - Asynchronous unbuffered query (alias to QueryStreamAsync)
  • QueryPartialUnbuffered<T>() - Partial mapping unbuffered query
  • QueryPartialUnbufferedAsync<T>() - Partial mapping async unbuffered query

Best Practices

Use for Large Result Sets

Use streaming methods when processing large result sets to avoid memory issues:

// For large result sets, use streaming instead of loading all into memory
var products = connection.Query<Product>("SELECT * FROM products");  // Loads all into memory

// Better for large datasets
foreach (var product in connection.QueryStream<Product>("SELECT * FROM products"))
{
    // Process one at a time
    ProcessProduct(product);
}

Connection Management

Be aware of connection state during streaming:

// The connection remains open during enumeration
// Don't use the connection for other operations during streaming
foreach (var product in connection.QueryStream<Product>("SELECT * FROM products"))
{
    // Connection is busy with this query
    // Don't execute other queries on the same connection here
    ProcessProduct(product);
} // Connection is closed after enumeration completes

Use Partial Mapping When Appropriate

Use partial mapping when you don't need all entity properties:

// When you only need a subset of properties
var products = connection.QueryPartialStream<Product>("SELECT product_id, product_name FROM products");

// This avoids strict mapping errors when not all entity properties have matching columns

Performance Considerations

  • Memory Efficiency: Streaming methods only hold one entity in memory at a time, making them ideal for large result sets
  • Connection Usage: The connection remains open during the entire enumeration process
  • Lazy Evaluation: Entities are only read from the database as they are enumerated
  • Buffering: Unlike regular Query methods, streaming methods don't buffer all results in memory
  • Async Streaming: Use async streaming methods for better scalability in web applications
