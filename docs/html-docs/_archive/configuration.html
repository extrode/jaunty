Configuration

Global configuration options and command-level settings for Jaunty

Home > Overview > Configuration

Overview

Jaunty provides both global configuration options through JauntyConfig and command-level settings through CommandOptions. Global configuration affects all queries, while command options allow per-operation customization.

Global Configuration (JauntyConfig)

Global configuration options are set once at application startup and affect all queries throughout the application lifecycle.

SchemaNameResolver

Global resolver for schema names. Receives the entity type and returns the schema name to use.

public static Func<Type, string>? SchemaNameResolver { get; set; }

Example

// Set at application startup
JauntyConfig.SchemaNameResolver = type => "dbo";

// Or use a more complex resolver
JauntyConfig.SchemaNameResolver = type => 
    type.Namespace?.Split('.').Last() ?? "dbo";

TableNameResolver

Global resolver for table names. Receives the entity type and returns the table name to use.

public static Func<Type, string>? TableNameResolver { get; set; }

Example

// Use plural table names
JauntyConfig.TableNameResolver = type => $"{type.Name}s";

// Use snake_case plural table names
JauntyConfig.TableNameResolver = type => NamingConvention.SnakeCasePluralTable(type.Name);

ColumnNameResolver

Global resolver for column names. Receives the property name and returns the column name to use.

public static Func<string, string>? ColumnNameResolver { get; set; }

Example

// Use snake_case column names
JauntyConfig.ColumnNameResolver = propertyName => NamingConvention.ToSnakeCase(propertyName);

// Use lowercase column names
JauntyConfig.ColumnNameResolver = propertyName => propertyName.ToLower();

Reset()

Resets all configuration to their default values (null).

public static void Reset()

Example

// Reset all configuration to defaults
JauntyConfig.Reset();

Naming Convention Helpers

Built-in helpers for common naming conventions.

NamingConvention.ToSnakeCase(string input)

Converts a PascalCase or camelCase string to snake_case.

public static string ToSnakeCase(string input)

Example

var result = NamingConvention.ToSnakeCase("ProductName"); // "product_name"
var result2 = NamingConvention.ToSnakeCase("categoryId"); // "category_id"

NamingConvention.Pluralize(string singular)

Converts a singular noun to its plural form.

public static string Pluralize(string singular)

Example

var result = NamingConvention.Pluralize("Category"); // "Categories"
var result2 = NamingConvention.Pluralize("Product"); // "Products"

NamingConvention.SnakeCasePluralTable(string typeName)

Converts a type name to snake_case plural table name.

public static string SnakeCasePluralTable(string typeName)

Example

var result = NamingConvention.SnakeCasePluralTable("Product"); // "products"
var result2 = NamingConvention.SnakeCasePluralTable("Category"); // "categories"

Command Options

Per-operation configuration options that can be passed to query methods.

CommandOptions<T>

Generic command options for operations that return entities of type T.

public readonly struct CommandOptions<T>(Func<IDataReader, T>? mapper = null, IDbTransaction? transaction = null, int? commandTimeout = null)

Properties

  • Mapper: Custom mapper function for entity mapping
  • Transaction: Database transaction to use
  • CommandTimeout: Command timeout in seconds

Static Factory Methods

  • WithMapper(Func<IDataReader, T> mapper): Create options with custom mapper
  • WithTransaction(IDbTransaction transaction): Create options with transaction
  • WithTimeout(int seconds): Create options with command timeout
  • With(Func<IDataReader, T> mapper, IDbTransaction transaction, int timeoutSeconds): Create options with all parameters

Example

using var transaction = connection.BeginTransaction();
var options = CommandOptions<Product>.WithTransaction(transaction);

var products = connection.Query<Product>(
    "SELECT * FROM products WHERE category_id = @CategoryId", 
    new { CategoryId = 1 }, 
    options);

CommandOptions (Non-Generic)

Non-generic command options for scalar operations that don't require a specific entity type.

public readonly struct CommandOptions(IDbTransaction? transaction = null, int? commandTimeout = null)

Properties

  • Transaction: Database transaction to use
  • CommandTimeout: Command timeout in seconds

Static Factory Methods

  • WithTransaction(IDbTransaction transaction): Create options with transaction
  • WithTimeout(int seconds): Create options with command timeout
  • With(IDbTransaction transaction, int timeoutSeconds): Create options with both parameters

Example

var options = CommandOptions.WithTimeout(30);
var count = connection.QueryScalar<int>("SELECT COUNT(*) FROM products", options);

Configuration Priority

Jaunty uses the following priority order for determining table/column names:

  1. Attributes ([Table], [Column], [Ignore], [Key], [DatabaseGenerated]) - Highest priority
  2. JauntyConfig resolvers (SchemaNameResolver, TableNameResolver, ColumnNameResolver) - Medium priority
  3. Default behavior (property/type names) - Lowest priority

Example of Priority Order

// If you have this configuration:
JauntyConfig.ColumnNameResolver = NamingConvention.ToSnakeCase;

// And this entity:
public class Product
{
    [Column("legacy_product_id")]  // This takes highest priority
    public int ProductId { get; set; }  // Would normally map to "product_id" with snake_case
    
    public string ProductName { get; set; }  // This will use snake_case: "product_name"
}

Best Practices

Set Configuration at Startup

Configuration should be set once at application startup before any queries are executed:

public void ConfigureServices(IServiceCollection services)
{
    // Set Jaunty configuration at startup
    JauntyConfig.ColumnNameResolver = NamingConvention.ToSnakeCase;
    JauntyConfig.TableNameResolver = NamingConvention.SnakeCasePluralTable;
    
    // Register your database connection
    services.AddScoped<IDbConnection>(provider => 
        new SqlConnection(connectionString));
}

Use Attributes for Specific Overrides

Use attributes for specific entity or property overrides:

// If most tables follow snake_case convention but one is different
[Table("legacy_products")]  // Override the global convention
public class Product
{
    [Column("prod_id")]  // Override the global convention
    public int ProductId { get; set; }
    
    public string ProductName { get; set; } = string.Empty;
}
