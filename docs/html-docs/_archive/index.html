Jaunty

A high-performance micro-ORM for .NET that executes SQL and maps results to objects with strict mapping by default

Overview Query Methods CRUD Operations Fluent API Configuration

Core Features

Jaunty provides a clean, performant API for data access in .NET applications

Strict by Default

All entity properties must have matching columns in the result set. This prevents silent mapping bugs that can occur with loose mapping.

High Performance

Uses compiled expression trees and metadata caching for optimal performance. Minimal allocations during query execution.

Modern C#

Leverages C# 13 extension syntax, full async/await support, and IAsyncEnumerable for streaming large result sets.

Quick Start

Getting started with Jaunty is simple and straightforward

// Install the NuGet package
dotnet add package Beparey.Jaunty

// Basic usage
using Jaunty;

var products = connection.Query<Product>(
    "SELECT * FROM products WHERE category_id = @CategoryId", 
    new { CategoryId = 1 });

// With strict and partial mapping
var strictProducts = connection.Query<Product>(sql);           // All properties must match
var partialProducts = connection.QueryPartial<Product>(sql);   // Only map existing columns
