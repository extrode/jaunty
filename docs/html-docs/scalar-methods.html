Scalar Methods

Execute SQL queries that return single scalar values (first column of first row)

Home > Overview > Scalar Methods

Overview

Scalar methods execute SQL queries and return the value from the first column of the first row. These methods are ideal for aggregate functions like COUNT, SUM, AVG, etc., or for queries that return a single value.

Basic Scalar Operations

QueryScalar<T>(string sql)

Executes a query and returns the first column of the first row as a scalar value of type T.

public static T QueryScalar<T>(this IDbConnection connection, string sql)

Parameters

Name Type Description
connection IDbConnection The database connection
sql string The SQL query to execute

Returns

T: The scalar value of type T from the first column of the first row

Example

// Get count of records
var count = connection.QueryScalar<int>("SELECT COUNT(*) FROM products");

// Get maximum price
var maxPrice = connection.QueryScalar<decimal>("SELECT MAX(price) FROM products");

// Get a specific value
var productName = connection.QueryScalar<string>("SELECT product_name FROM products WHERE product_id = 1");

QueryScalar<T>(string sql, object parameters)

Executes a parameterized query and returns the first column of the first row as a scalar value of type T.

public static T QueryScalar<T>(this IDbConnection connection, string sql, object parameters)

Parameters

Name Type Description
connection IDbConnection The database connection
sql string The SQL query to execute
parameters object Parameters for the query

Returns

T: The scalar value of type T from the first column of the first row

Example

// Get count with parameter
var count = connection.QueryScalar<int>(
    "SELECT COUNT(*) FROM products WHERE category_id = @CategoryId", 
    new { CategoryId = 1 });

// Get average price for a specific category
var avgPrice = connection.QueryScalar<decimal>(
    "SELECT AVG(price) FROM products WHERE category_id = @CategoryId", 
    new { CategoryId = 2 });

QueryScalar<T>(string sql, CommandOptions options)

Executes a query with command options and returns the first column of the first row as a scalar value of type T.

public static T QueryScalar<T>(this IDbConnection connection, string sql, CommandOptions options)

Parameters

Name Type Description
connection IDbConnection The database connection
sql string The SQL query to execute
options CommandOptions Command options (transaction, timeout)

Returns

T: The scalar value of type T from the first column of the first row

Example

using var transaction = connection.BeginTransaction();
try
{
    var count = connection.QueryScalar<int>(
        "SELECT COUNT(*) FROM products", 
        CommandOptions.WithTransaction(transaction));
    
    transaction.Commit();
}

Common Use Cases

Aggregate Functions

Scalar methods are ideal for aggregate functions:

// Count records
var count = connection.QueryScalar<int>("SELECT COUNT(*) FROM products");

// Get maximum value
var maxPrice = connection.QueryScalar<decimal>("SELECT MAX(price) FROM products");

// Get average value
var avgPrice = connection.QueryScalar<double>("SELECT AVG(price) FROM products");

// Get minimum value
var minPrice = connection.QueryScalar<decimal>("SELECT MIN(price) FROM products");

// Get sum
var totalValue = connection.QueryScalar<decimal>("SELECT SUM(price) FROM products");

Lookup Values

Get specific values from the database:

// Get a specific ID
var productId = connection.QueryScalar<int>("SELECT product_id FROM products WHERE product_name = @ProductName", new { ProductName = "Widget" });

// Get a string value
var categoryName = connection.QueryScalar<string>("SELECT category_name FROM categories WHERE category_id = @CategoryId", new { CategoryId = 1 });

// Get a date/time value
var lastModified = connection.QueryScalar<DateTime>("SELECT MAX(last_modified) FROM products");

Notes

  • Scalar methods return the value from the first column of the first row in the result set
  • If the result set is empty, an InvalidOperationException is thrown
  • For nullable return types, use QueryScalar<T?> to handle potentially null values
  • For async operations, the connection must be a DbConnection rather than just IDbConnection
  • Command options allow specifying transactions and timeouts for scalar operations
  • Scalar operations work with all supported database providers (SQL Server, SQLite, PostgreSQL, MySQL)
