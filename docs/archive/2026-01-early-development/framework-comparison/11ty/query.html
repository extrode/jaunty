Query<T>

Executes a SQL query and returns a list of mapped entities with strict type safety.

ⓘ Strict Mapping Mode

By default, Query<T> uses strict mapping. All properties on T must have matching columns in the result set, or an InvalidOperationException is thrown.

Declaration

public static List<T> Query<T>(
    this IDbConnection connection,
    string sql,
    object? parameters = null,
    CommandOptions<T>? options = null,
    CancellationToken cancellationToken = default)
where T : new()

Parameters

Name Type Description
connection IDbConnection The database connection to execute the query against.
sql string The SQL query to execute. Supports both named (@param) and positional parameters.
parameters object? Optional parameters for the query. Can be an anonymous object or array of values for positional parameters.
options CommandOptions<T>? Optional command options for transaction, timeout, or custom mapper configuration.
cancellationToken CancellationToken Optional token to cancel the query operation.

Returns

List<T> - A list of entities mapped from the query results.

Examples

Basic Query

public class Product
{
    public int Id { get; set; }
    public string Name { get; set; }
    public decimal Price { get; set; }
}

// Execute a simple query
var products = connection.Query<Product>("SELECT * FROM products");

Query with Named Parameters

// Using anonymous object for named parameters
var products = connection.Query<Product>(
    "SELECT * FROM products WHERE category_id = @CategoryId AND price > @MinPrice",
    new { CategoryId = 5, MinPrice = 100.00m });

Query with Positional Parameters

// Positional parameters (values bound in order)
var products = connection.Query<Product>(
    "SELECT * FROM products WHERE category_id = @CategoryId AND price > @MinPrice",
    5, 100.00m);

Query with Transaction

using var transaction = connection.BeginTransaction();

var products = connection.Query<Product>(
    "SELECT * FROM products WHERE category_id = @CategoryId",
    new { CategoryId = 5 },
    CommandOptions<Product>.WithTransaction(transaction));

transaction.Commit();

Exceptions

Type Condition
InvalidOperationException Thrown when a property on T has no matching column in the result set (strict mapping mode).
InvalidOperationException Thrown when a non-nullable property receives a NULL value from the database.
ArgumentException Thrown when the number of provided parameters doesn't match the number of parameters in the SQL.
ArgumentNullException Thrown when connection or sql is null.
DbException Thrown when the database operation fails (e.g., syntax error, constraint violation).

Remarks

  • Connection Management: If the connection is closed, Jaunty opens it before execution and closes it after. If the connection is already open, it remains open after execution.
  • Mapping Mode: This method uses strict mapping by default. For partial mapping (where only existing columns are mapped), use QueryPartial<T> instead.
  • Performance: Entity metadata is cached on first use. Subsequent queries of the same type have minimal overhead.
  • Special Types: Query also supports Dictionary<string, object>, ExpandoObject, KeyValuePair<TKey, TValue>, and ValueTuple as generic type arguments.
