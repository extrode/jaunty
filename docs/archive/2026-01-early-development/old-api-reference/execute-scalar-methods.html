ExecuteScalar Methods

Execute SQL commands that return a single scalar value (first column of first row)

Home > Overview > ExecuteScalar Methods

Overview

ExecuteScalar methods execute SQL commands and return the value from the first column of the first row in the result set. These methods are ideal for aggregate functions like COUNT, SUM, AVG, etc., or for queries that return a single value.

Synchronous ExecuteScalar Methods

ExecuteScalar<T>(string sql)

Executes a command and returns the first column of the first row as a scalar value of type T.

public static T ExecuteScalar<T>(this IDbConnection connection, string sql)

Parameters

Name Type Description
connection IDbConnection The database connection
sql string The SQL command to execute

Returns

T: The scalar value of type T from the first column of the first row

Example

// Get count of records
var count = connection.ExecuteScalar<int>("SELECT COUNT(*) FROM products");

// Get maximum price
var maxPrice = connection.ExecuteScalar<decimal>("SELECT MAX(price) FROM products");

// Get a specific value
var productName = connection.ExecuteScalar<string>("SELECT product_name FROM products WHERE product_id = 1");

ExecuteScalar<T>(string sql, object parameters)

Executes a parameterized command and returns the first column of the first row as a scalar value of type T.

public static T ExecuteScalar<T>(this IDbConnection connection, string sql, object parameters)

Parameters

Name Type Description
connection IDbConnection The database connection
sql string The SQL command to execute
parameters object Parameters for the command

Returns

T: The scalar value of type T from the first column of the first row

Example

// Get count with parameter
var count = connection.ExecuteScalar<int>(
    "SELECT COUNT(*) FROM products WHERE category_id = @CategoryId", 
    new { CategoryId = 1 });

// Get average price for a specific category
var avgPrice = connection.ExecuteScalar<decimal>(
    "SELECT AVG(price) FROM products WHERE category_id = @CategoryId", 
    new { CategoryId = 2 });

ExecuteScalar<T>(string sql, CommandOptions options)

Executes a command with options and returns the first column of the first row as a scalar value of type T.

public static T ExecuteScalar<T>(this IDbConnection connection, string sql, CommandOptions options)

Parameters

Name Type Description
connection IDbConnection The database connection
sql string The SQL command to execute
options CommandOptions Command options (transaction, timeout)

Returns

T: The scalar value of type T from the first column of the first row

Example

using var transaction = connection.BeginTransaction();
try
{
    var count = connection.ExecuteScalar<int>(
        "SELECT COUNT(*) FROM products", 
        CommandOptions.WithTransaction(transaction));
    
    transaction.Commit();
}

Common Use Cases

Aggregate Functions

ExecuteScalar methods are ideal for aggregate functions:

// Count records
var count = connection.ExecuteScalar<int>("SELECT COUNT(*) FROM products");

// Get maximum value
var maxPrice = connection.ExecuteScalar<decimal>("SELECT MAX(price) FROM products");

// Get average value
var avgPrice = connection.ExecuteScalar<double>("SELECT AVG(price) FROM products");

// Get minimum value
var minPrice = connection.ExecuteScalar<decimal>("SELECT MIN(price) FROM products");

// Get sum
var totalValue = connection.ExecuteScalar<decimal>("SELECT SUM(price) FROM products");

Lookup Values

Get specific values from the database:

// Get a specific ID
var productId = connection.ExecuteScalar<int>("SELECT product_id FROM products WHERE product_name = @ProductName", new { ProductName = "Widget" });

// Get a string value
var categoryName = connection.ExecuteScalar<string>("SELECT category_name FROM categories WHERE category_id = @CategoryId", new { CategoryId = 1 });

// Get a date/time value
var lastModified = connection.ExecuteScalar<DateTime>("SELECT MAX(last_modified) FROM products");

Important Notes

  • Return Value: ExecuteScalar returns the value from the first column of the first row in the result set
  • Empty Results: If the result set is empty, ExecuteScalar will typically return the default value for the type (0 for numeric types, null for reference types)
  • Multiple Rows: ExecuteScalar only considers the first row, ignoring any additional rows in the result set
  • Async Requirements: Async operations require a DbConnection rather than just IDbConnection
  • Command Options: All ExecuteScalar methods support command options for transactions and timeouts
  • Database Compatibility: ExecuteScalar works with all supported database providers (SQL Server, SQLite, PostgreSQL, MySQL)

Best Practices

Use Appropriate Return Types

Match the return type to the expected database column type:

// For integer counts
var count = connection.ExecuteScalar<int>("SELECT COUNT(*) FROM products");

// For decimal prices
var price = connection.ExecuteScalar<decimal>("SELECT MAX(price) FROM products");

// For nullable values
var description = connection.ExecuteScalar<string?>("SELECT description FROM products WHERE product_id = @Id", new { Id = 1 });

Handle Potential Nulls

Consider using nullable types when the result might be NULL:

// When the column might be NULL in the database
var nullableValue = connection.ExecuteScalar<int?>("SELECT nullable_column FROM table WHERE condition = @condition", new { condition = "value" });

// Check for null before using
if (nullableValue.HasValue)
{
    ProcessValue(nullableValue.Value);
}
